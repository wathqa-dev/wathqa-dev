# Abdennour B.

I build tools for problems that don't get solved, because the people
with the problem aren't the people with the keyboards.

Most software assumes a world that's fast, English, cloud-connected,
and fully documented. That world isn't most places. I build for the
places it isn't.

---

## What I care about

- **Tools that assume nothing.** No fast internet, no cloud account,
  no credit card, no English. If it needs those to work, it's not done.
- **Boring tech, careful craft.** A working SQLite file beats a
  beautiful distributed system that never ships.
- **Languages nobody builds for.** Darija, Arabic, French — not
  translation layers bolted on at the end.
- **Build for the people everyone else skipped.** They're not a niche.
  They're most of the world.
